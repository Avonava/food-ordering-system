# 🍔 Food Ordering System — Java Swing

A lightweight desktop application built with **Java Swing** to manage food orders in a fast, efficient, and user-friendly way. Perfect for cafés, canteens, or university lounges 🍽️

---

## 🚀 Features

- 🔐 **Secure Login**
  - Admin & Cashier access
- 📋 **Menu Management**
  - Add/update/delete food items by category
- 🛒 **Order System**
  - Select items with quantity, calculate total in real-time
- 🧾 **Billing Module**
  - Auto total + tax, and generates printable receipts
- 📈 **Sales Report**
  - Track daily income and orders
- 💼 **User-Friendly Dashboard**
  - Clean interface, simple navigation

---

## 🧰 Tech Stack

- `Java` — Core programming
- `Swing` — UI framework
- `MySQL` — Backend database
- `JDBC` — Database connectivity
- `NetBeans` or `IntelliJ` — IDE (recommended)
